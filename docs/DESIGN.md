# EasyGit 设计语言 v1

> 克制扁平 · 开发者风 · 青碧 Teal
> 实现位置:`src/main/resources/css/theme.css`(令牌与控件规则),本文档是令牌表与使用规则。

## 定位

EasyGit 是高频使用的 Git 桌面工具。设计语言服务于**长时间注视下的可读性与操作确定性**:
平静的分层表面、细描边、品牌色只做点睛。不追趸渐变玻璃拟态,不堆投影。

五条原则:

1. **分层表面** —— 界面深度只靠三层表面 + 描边表达,不靠阴影:
   `-bg`(页面底) / `-panel`(面板·卡片·工具栏) / `-panel2`(悬停·下沉·次级) / `-overlay`(弹层)。
2. **细描边** —— 平面元素用 1px `-border` 描边;投影只允许出现在弹层(菜单/提示气泡)上。
3. **accent 点睛** —— 青碧只用于:选中态、主按钮、链接、焦点环、进度。不大面积铺色。
4. **圆角三档** —— `-radius-s: 4`(徽标/行内悬停) / `-radius: 6`(按钮/输入框) / `-radius-l: 8`(弹层/卡片)。
5. **亮暗同源** —— 亮色默认(`.root`),暗色 = `.root.dark` 换一套令牌,结构规则完全共用。

### 品牌青碧(三档,职责固定)

| 令牌 | 亮色 | 暗色 | 职责 |
|---|---|---|---|
| `-accent` | `#0f766e` | `#2dd4bf` | **文字级**:链接、选中文字、强调、hunk 头文字。亮色下白底对比 5.5:1 |
| `-accent-deep` | `#0b5d57` | `#12857c` | **填充级**:主按钮、勾选框底、进度条,白字对比 ≥4.5:1 |
| `-accent-soft` | `#d5ebe8` | `#113733` | **面积型 tint**:hunk 头底、徽标底 |

暗色下两档互换亮度角色(文字用亮青碧、填充用深青碧),保证两种对比都成立。

### 字阶 / 图形

- 字阶:11px(meta/section) / 12px(console/tooltip) / **13px(基准)** / 15px(h2) / 22px(h1) / 34px(欢迎页)。
- 等宽:`.mono`(Consolas / Menlo / DejaVu Sans Mono / Noto Sans Mono),用于哈希、diff、路径。
- 提交图泳道色(Java 端,`HistoryPanel`/`BlameView` 共用):青碧主色领衔

## 布局语言(全出血面板 · 桌面风)

- **面板贴满窗口,不搞网页式留白**(这是桌面程序):头部条与底部状态条/输出面板
  全宽附着,左侧栏与中部内容区全出血,区域之间只靠 1px hairline 分界
  (`.side-panel` 仅右侧描边)。曾试过「画布+浮动卡片」的 8px 呼吸缝,被否——桌面程序要贴边。
- **窗口 = 系统标准装饰**:不自绘标题栏/窗控/圆角/投影(平台模拟方案——自定义标题栏、
  TRANSPARENT 圆角窗体、mac 红绿灯、平台字体分支——实现过一轮,被否)。
  遵循 JavaFX(Modena)基座,自绘只做配色与控件细节;应用内头部条是**命令栏**,不是标题栏。
- **信息架构**(0.2 重构):全局命令收纳进头部条,不再堆一排平铺按钮——
  仓库切换器(仓库列表 + 打开/克隆/初始化)、⇣ 同步(拉取/推送/抓取)、⟳ 刷新、
  ⋯ 更多(Blame、LFS)、输出/主题/设置图标按钮;
  分支操作(新建/合并)归位到侧栏分支区头;真正高频的操作(提交)留在变更面板。
- **面板头统一**:`Fx.panelHead(标题, 右侧操作...)` 是所有面板标题行的唯一来源,
  节奏(padding/字重/间距)由 `.panel-head` 一处控制。
- **对齐基准 = 12px 内容边距**:面板头全宽自带 12px 内距、内容区包一层 12px wrapper、
  页脚全宽自绘底色且内距 12——同页面所有框/文字左缘落在同一基准线
  (MainShellProbe 有对齐审计:三框左缘彼此差 <1.5px)。
- 变更面板 = 横向分栏「文件清单 | 差异查看器」+ 底部**提交页脚卡**(`.commit-footer`)。
- 页签区与内容同面:页签头/内容区均为 `-panel`,选中页签 = 底边 2px 下划线。
- 欢迎页 = hero:大标题 + 三张入口卡片(`.action-card`,hover 描边转 accent)。
- MenuButton(切换器/同步/更多)幽灵化:透明底,hover 显 `-panel2` 圆角面。

## 控件规范(要点)

- **按钮**:面板底 + 1px `-border` 描边;hover 面变 `-panel2`、描边转 `-border-strong`;按下 `-border`。
  主按钮 `.primary`:`-accent-deep` 底 + 白字,无边框。幽灵按钮 `.ghost`:无边框纯文字,hover 显 `-panel2`。
- **输入框**:面板底 + `-border` 描边;**聚焦描边转 `-accent`**(焦点反馈的统一语言)。
- **列表/树**:单元格默认透明;悬停/选中是**两侧留白 4px(树 2px)的圆角块** `-radius-s`。
  例外:diff 列表行底纹必须满幅铺,`.diff-list` 单元格显式还原 `insets: 0 / radius: 0`。
- **标签页**:下划线式(VS Code 风)——选中 tab 底边 2px `-accent` + 文字加重;
  规则用 `TabPane` 类型前缀提权(方位伪类 `.tab:top` 在 Modena 里权重更高)。
- **菜单/提示**:投影使用者;条目悬停为圆角块。
- **文件行**:类型圆点 + 路径 + 等宽 `+/−` 徽标(`.stat-add`/`.stat-del` 语义色)。
- **滚动条**:无轨道,`-border-strong` 细圆角滑块,hover 转 `-fg-dim`。
- **复选框**:4px 圆角方框,选中填 `-accent-deep` + 白勾。

## 使用规则(给后续开发)

1. 新 UI 一律引用令牌,**不要在 Java 或 CSS 里写死颜色/圆角**;确需新色先加令牌再引用。
2. 悬停/选中/聚焦/禁用四态要给全,宁可少层次也不要丢状态反馈。
3. JavaFX 陷阱备忘(详见项目记忆):
   - 嵌套 Label 上色必须用 `.xxx .label` 直接命中,写在父节点的 `-fx-text-fill` 是继承值,会输给 Modena;
   - 覆盖自有基础规则时选择器权重必须 ≥ 原规则(基础列表规则是 (0,6,0));
   - `Node.snapshot` 验证前先 `setFill(Color.TRANSPARENT)`,否则 alpha 指标全部失效。
4. 验证:`target/harness/DesignSystemProbe`(亮/暗双主题控件图库截图)。
